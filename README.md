# EMT Tracker

Personal tracker for SoCal ambulance applications and other EMT opportunities near UCLA.

## Features

- 11 companies including **MedReach**, Lynch EMS, McCormick, AMR, Falck, LifeLine, and more
- Separate **Other EMT opportunities** section for event-work leads, with eligibility notes and source links
- Track status, applied date, and notes per company (saved in browser)
- Search, filter by type/status, sort by pay / hire speed / difficulty
- Export / import JSON backups

## Develop

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```
